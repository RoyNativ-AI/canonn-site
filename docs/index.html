API reference

Canonn serves one model, canonn-r1, tuned for a single job: answering from the documents you give it, declining when the answer is not there, and flagging passages that contradict each other.

The API is OpenAI-compatible. Point any OpenAI SDK at https://api.canonn.ai/v1, swap the key, and your existing code works. There is nothing else to learn — the rest of this page is detail you may never need.

BASEhttps://api.canonn.ai/v1

Authentication

Create a key in the dashboard and send it as a bearer token. A key is shown once at creation and stored only as a hash: it cannot be recovered later, only revoked and replaced.

Header
Authorization: Bearer canonn-sk-...

New accounts get 1,000 free calls a month with no card. Past that, add credits in the dashboard.

How to prompt it

Put the documents in the system message and the question in the user message. That is the whole technique.

Do not write a rulebook. Faithfulness is trained into the weights, not instructed at runtime. Instructions like "only use the provided context, do not hallucinate, cite your sources" cost tokens on every call and dilute attention — Canonn behaves that way without them.

Prompt shape
// system
Answer from the data below.

Data: Refunds are accepted within 45 days of purchase.

// user
What is the refund window?

Quickstart

A complete, runnable call. Replace the key and go.

curl --location 'https://api.canonn.ai/v1/chat/completions' \
--header 'Authorization: Bearer canonn-sk-...' \
--header 'Content-Type: application/json' \
--data '{
  "model": "canonn-r1",
  "messages": [
    {
      "role": "system",
      "content": "Answer from the data below.\n\nData: Refund window: 45 days from purchase."
    },
    {
      "role": "user",
      "content": "How long do I have to request a refund?"
    }
  ]
}'
from openai import OpenAI

client = OpenAI(
    base_url="https://api.canonn.ai/v1",
    api_key="canonn-sk-...",
)

answer = client.chat.completions.create(
    model="canonn-r1",
    messages=[
        {"role": "system", "content": "Answer from the data below.\n\nData: Refund window: 45 days from purchase."},
        {"role": "user", "content": "How long do I have to request a refund?"},
    ],
)

print(answer.choices[0].message.content)

Chat completions

POST/v1/chat/completions

Creates a grounded answer. Same request and response shape as the OpenAI endpoint of the same name.

Body

FieldTypeDescription
messages requiredarrayDocuments in the system message, question in the user message. Prior turns may be included.
modelstringAlways canonn-r1. Unknown values are normalised rather than rejected, so older integrations keep working.
streambooleanServer-sent events instead of one JSON body. Default false.
temperaturenumberDefault 0. Leave it there for extraction work — higher values add variance, not insight.
max_tokensintegerCap on the answer length.
top_pnumberNucleus sampling.
stopstring or arraySequences that end generation.
seedintegerSame seed and inputs produce the same answer.

When the answer is not in the data

This is the behaviour Canonn exists for. Ask something the documents do not cover and it says so, instead of inventing a plausible answer.

Request
{
  "model": "canonn-r1",
  "messages": [
    { "role": "system", "content": "Answer from the data below.\n\nData: Plan A costs 10 dollars per month." },
    { "role": "user", "content": "How much does Plan B cost?" }
  ]
}
Answer
"The data provided does not contain information about Plan B,
 so the cost cannot be determined."

Finish reasons

ValueMeaning
stopThe model finished its answer.
lengthCut off by max_tokens. Raise it and retry rather than shipping a truncated answer.

Streaming

Set stream: true to receive tokens as they are generated. Chunks arrive as data: lines and the stream ends with data: [DONE].

Use streaming for long answers. A non-streamed generation that runs past about 100 seconds can hit the edge's first-byte timeout; a streamed one is unaffected once the first chunk flows.

curl -N --location 'https://api.canonn.ai/v1/chat/completions' \
--header 'Authorization: Bearer canonn-sk-...' \
--header 'Content-Type: application/json' \
--data '{"model":"canonn-r1","stream":true,"messages":[
  {"role":"system","content":"Answer from the data below.\n\nData: Support hours are 9am to 5pm on weekdays."},
  {"role":"user","content":"Is support available on Saturday?"}]}'

data: {"choices":[{"delta":{"content":"No"},"finish_reason":null}], ...}
data: {"choices":[{"delta":{},"finish_reason":"stop"}], ...}
data: [DONE]
stream = client.chat.completions.create(
    model="canonn-r1",
    stream=True,
    messages=[
        {"role": "system", "content": "Answer from the data below.\n\nData: Support hours are 9am to 5pm on weekdays."},
        {"role": "user", "content": "Is support available on Saturday?"},
    ],
)

for chunk in stream:
    delta = chunk.choices[0].delta.content
    if delta:
        print(delta, end="", flush=True)

Demo

POST/v1/demo

Powers the public playground on canonn.ai. No key, rate limited per IP, with tighter length limits than the main endpoint. Useful for a quick taste before you sign up.

cURL
curl --location 'https://api.canonn.ai/v1/demo' \
--header 'Content-Type: application/json' \
--data '{"data":"Refund window: 45 days from purchase.",
        "question":"How long do I have to request a refund?"}'

→ {"answer":"The refund window is 45 days from purchase.","seconds":0.8}

Errors

Errors carry the appropriate HTTP status and a JSON body of the shape {"error": "message"}.

StatusMeaning
400Malformed body — usually invalid JSON or a missing field.
401Missing, malformed, or revoked key.
402Free-tier allowance spent and no credits on the account.
429Too many requests in the current window.
502The model could not be reached. Retry — these are not billed.

SDKs and tools

Any OpenAI-compatible client works — official SDKs, LangChain, LlamaIndex, Vercel AI SDK. Set the base URL to https://api.canonn.ai/v1 and the model to canonn-r1.

The full machine-readable specification is published as OpenAPI 3.1 (JSON) — import it into Postman, Insomnia, or Apidog to get a working collection in one step.
