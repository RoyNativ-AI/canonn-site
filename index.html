How it works

Faithfulness, trained in — not prompted on.

Canonn is a three-stage system that reads retrieved data, keeps only what answers the question, and responds from it — in one turn or across a conversation.

STAGE 01 · ROUTE

Know when data matters

A lightweight router decides whether a question needs the retrieved data or is ordinary conversation — so the faithful core only runs when it should.

STAGE 02 · GROUND

Answer from the data

The trained core obeys the retrieved passages over its own priors, filters out irrelevant chunks, and never invents beyond what's provided.

STAGE 03 · CONVERSE

Hold the thread

It answers the actual question in context — first message or deep in a conversation — carrying history without losing faithfulness to the source.
